# Public Asset Directory

You can upload your 8K images and 4K videos directly into this directory (`/public/`):

1. **`logo-dark.png`** — High-resolution transparent PNG logo for Dark Mode.
2. **`logo-light.png`** — High-resolution transparent PNG logo for White Mode.
3. **`hero-video.mp4`** — Cinematic 4K/8K background video banner.

The app automatically detects and renders these files when uploaded here!
